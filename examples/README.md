# Executable examples

These scripts explain mathematical workflows and check their results. Run them from a source checkout after installing the package and its required dependencies.

| Script | Question | Prerequisites |
|---|---|---|
| [certified_limits.py](certified_limits.py) | Does a simultaneous limit exist, and what proves it? | Core package |
| [branch_limits.py](branch_limits.py) | How do fixed rays choose a cut value or pole direction? | Core package |
| [special_function_limits.py](special_function_limits.py) | Can a harmonic tail or gamma ratio avoid generic series work? | Core package |
| [ordinary_expansion.py](ordinary_expansion.py) | How are terms and remainders represented? | Core package |
| [common_algebra.py](common_algebra.py) | How do asymptotic representations compose? | Core package |
| [asymptotic_summation.py](asymptotic_summation.py) | What controls a sum's leading growth? | Core package |
| [probability_asymptotics.py](probability_asymptotics.py) | What does a probability approximation certify? | Core package |
| [perturbation_problem.py](perturbation_problem.py) | How are a perturbation regime and residual validated? | Core package; ODE integration for differential-equation workflows |

Specialist examples are in [expert](expert). Read the [capability matrix](../docs/capabilities.md) before extrapolating a demonstration to other orders, sectors or parameter ranges.
