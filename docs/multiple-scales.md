# Multiple scales

`multiple_scales` derives first slow modulation equations for weakly perturbed periodic oscillators while `multiple_scale_derivative` provides the underlying scale calculus independently of any solver.

For scales `T0=t` and `T1=eps*t`, the physical derivative is represented as

```text
D_t = D_0 + eps D_1
```

and arbitrary derivative orders are generated by repeated application instead of hard-coded formulas. Nonstandard scale powers can be supplied with `scale_orders`.

The automatic oscillator workflow constructs a common perturbation hierarchy, represents each leading oscillation with cosine and sine amplitudes depending on the first slow scale, and applies the package's periodic Fredholm projection machinery to the first correction equation. The resulting `MultipleScalesResult.modulation_equations` are slow-flow equations for those amplitudes.

Weak damping, weak nonlinearities, first-order coupling, and affine near-resonant forcing phases such as `(omega + eps*sigma)*t` are supported. Higher profile corrections remain symbolic when they are not solved; the result reports that limitation instead of accepting secular corrections.
